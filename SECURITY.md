# Keamanan / Security

## Pelaporan kerentanan / Reporting a vulnerability

**Bahasa Indonesia**

Jangan membuat issue publik untuk kerentanan keamanan. Laporkan secara privat melalui fitur **Report a vulnerability** pada tab **Security** di repositori GitHub ini. Sertakan langkah reproduksi, dampak, versi yang terdampak, dan kemungkinan mitigasi. Pengurus akan menanggapi laporan secepatnya.

**English**

Please do not open a public issue for a security vulnerability. Report it privately using **Report a vulnerability** under the repository's **Security** tab on GitHub. Include reproduction steps, impact, affected versions, and any suggested mitigation. The maintainers will respond as soon as possible.

## Versi yang didukung / Supported versions

Hanya versi terbaru pada branch `main` yang didukung untuk pembaruan keamanan.

Only the latest version on the `main` branch is supported for security updates.
